FPL Squad Builder

Runs entirely in your browser — nothing is sent to any server except the official FPL API (through a small relay, for technical reasons explained below).
What this is: a self-service version of this project's squad recommender and transfer suggester that anyone can use directly from this page — no GitHub account, no command line. It's a deliberately simplified port (see the README's "Browser tool" section for exactly what differs from the full version) — most accurate from gameweek 2 onward, once real in-season data exists. All scoring and optimization happens on your own device.

Relay URL (already set up for you)

Your browser can't call the official FPL API directly (it doesn't allow cross-site requests), so this page talks to it through a small relay — already deployed below, nothing for you to do. Only change this if it ever stops working (rate-limited, taken down, etc.) or you'd rather run your own — the README explains how to deploy a free one in a few minutes.

Find your team ID: log into the FPL website (not the app) on desktop, click "Points", and look at the address bar — it's the number after /entry/.
